# Claudio Quiroz — Portfolio

Portafolio personal de Claudio Quiroz, ingeniero de Procesos Industriales. Construido con [Astro](https://astro.build) y TypeScript, desplegado en Vercel: [cquirozipi.vercel.app](https://cquirozipi.vercel.app).

Incluye experiencia laboral, certificados, proyectos, stack de tecnologías y recomendaciones, todo con filtros por categoría y búsqueda donde aplica.

## Stack

- [Astro](https://astro.build) (SSG)
- TypeScript
- Tailwind CSS v4

## Desarrollo local

```bash
npm i
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
